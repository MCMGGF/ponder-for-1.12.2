## 已实现

- 描边在三维模型矩阵内绘制，不再把包围盒压成二维填色矩形。单块、不规则及离散选区保留原始位置，逐块读取原版选择范围；完整实心、单位形状、相同运行时变换的长方体合并为一个外框。策略与视角无关。
- 铁轨、台阶等使用当前预览状态的原版选择范围；读取失败时回退单位方块框。该范围不代表任意复杂模型或材质图案的精确几何边。
- 描边和信息锚点复用方块实际移动、旋转、淡入偏移及隐藏状态，不再由投影角点猜测所属结构。没有运行时记录的旧 Vec3d 空中锚点保留坐标回退；已知隐藏目标不产生原位幽灵框。
- 可见边和遮挡边采用 LEQUAL 清晰线／GREATER 同色淡线两遍绘制，均关闭深度写入；恢复线宽、深度、纹理、混合与客户端数组状态。私有缓冲区不占用全局 Tessellator。
- 同一 slot 只求值最新目标，chase 最多 6 个场景刻过渡；回退、跳步、暂停按照事件历史重新求值。选区几何按当前场景、状态和时间缓存，线段去重，切换／关闭时清理。
- 文本、操作提示和 GUI 根图及其子图按精确目标分组。每个信息框有独立文本／图片分页，不再把所有提示串为一个右侧段落。
- 信息框按上、右、左、下尝试定位，避开全部目标投影、人物八角点包围范围、菜单、按钮及其他信息框；小幅移动保留位置，大幅移动保持同侧跟随。空间不足时使用边缘分页浮框和目标切换控件。
- 模型区只由窗口和场景边界决定，信息内容、翻页、皮肤与信息框位置不改变取景。最小 320×240 逻辑界面用可读分页回退，不保证拥挤时每个目标同时有独立浮框。
- 信息框、引线及关联图片在普通界面之后的最终前景阶段绘制，始终面向屏幕，关闭深度测试与写入。原生 GUI 图片回调隔离矩阵、裁剪、视口和数组状态，返回后重新建立前景状态。“最前景”仅指 Ponder 界面。
- 点击、滚轮、按住拖动和翻页由信息框优先处理，阅读暂停播放，不传递给镜头或时间轴。分组菜单优先处理自身区域和翻页键，展开时暂停目标切换；临时悬停提示不丢失原教学页码。
- 保留原 showOutline、showOutlineWithText、pointAt(Vec3d)，增加文字及 GUI 的默认兼容 pointAt(Selection) 重载。事件存储不可变目标副本；outline_text 外部操作现在真正生成轮廓和同目标文字。
- 六类正式教学按“对象、操作、可观察结果”改写并绑定实际对象；合成、熔炉和物流图与文字共目标。保留燃料、延迟和时间压缩说明，不混入人物名称、POI 或内部调试描述。
