# Ponder Complex Test Scenes

这些场景全部使用 Minecraft 1.12.2 原版方块，不需要安装 Create。

## 打开方式

按 `P` 打开 Ponder 浏览器，然后选择 `Complex Feature Tests` 标签；也可以直接使用：

```text
/ponderui minecraft:observer 0
/ponderui minecraft:redstone 0
/ponderui minecraft:beacon 0
/ponderui minecraft:hopper 0
/ponderui minecraft:comparator 0
```

需要查看时间轴和运行时数据时，将 `ponderui` 改成 `ponderuidebug`。

## 场景检查点

### Observer: 自动熔炼生产线

- 输入、运输、处理、输出四部分应分阶段出现。
- 拉杆应从关闭切换到开启，再恢复关闭。
- 两个熔炉和顶部红石灯应同步点亮与熄灭。
- 原矿、煤炭和铁锭物品图标应移动，随后淡出。
- 烟雾、火焰、成功粒子不应被时间轴结尾截断。

### Redstone: 三路红石信号矩阵

- 三条红石线应依次切换到最高信号强度。
- 三盏灯应依次点亮。
- 中央中继器连续滚动三次时，延迟状态必须发生变化。
- 红、绿、蓝三条指示线和输入提示不能互相遮挡。

### Beacon: 四臂装配核心

- 四个独立区段应同时向外移动并绕共同中心旋转。
- 动画过程中不应被预览边缘裁掉。
- 中央核心应依次切换绿宝石、金块、钻石。
- 旋转后的实际方块位置和深度排序应与运行时边界一致。

### Hopper: 四向物流分拣中心

- 四种物品应从中央分别移动到西、东、北、南出口。
- 物品图标、目标文字、彩色路径线和成功粒子应按顺序出现。
- 玻璃板后面的方块仍应可见，不应出现整块黑色遮挡。
- 重播后每个物品的路径和消失时间应一致。

### Comparator: GUI 与文字布局实验室

- 熔炉、箱子、漏斗、酿造台面板应依次显示。
- 高度为 222 像素的箱子面板应自动缩小并保持在预览范围内。
- 中文说明框应自动避开 GUI 面板，并根据目标位置翻转方向。
- 最后的动态熔炉快照在拖动时间轴后不应错位或残留。

## 已知限制

- 普通实体 API 仍只有日志；当前可见 actor 是物品、鹦鹉和简化矿车。
- 方块破坏进度会更新数据，但暂时没有裂纹贴图。
- 移动/旋转区段上的文字、轮廓、控制点和 GUI 目标会按当前时间点同步变换；跨越多个相邻区段的自定义锚点仍建议使用区段中心，避免选择范围重叠。
- 第三方模组方块、TileEntity 和 GUI 兼容性需要单独测试，本组场景只验证 Ponder 核心功能。

如果场景出现空白，请在 `logs/latest.log` 搜索 `Ponder schematic`、`Ponder could not render` 或
`Ponder TileEntity`；加载器现在会报告错误资源路径和方块 ID。
