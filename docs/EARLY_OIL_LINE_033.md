# 前期石油生产线教学

## 安装与入口

这是 Airship Workshop 整合包的可选教学，串联包内已有的低压蒸汽锅炉、简易井口抽油机、常压分馏塔和燃油发电站。

将发行附件 `ponder_early_oil_line-<版本>.jar` 放入符合该整合包基线的 Cleanroom 客户端 `mods/` 目录，并安装同版本 Ponder 本体。只安装本体时不会出现油线分类或练习入口。附属包仅安装在客户端。

开发构建任务为 `remapOilLineJar`，产物位于 `build/optional-libs/`。运行 `oilLineTest` 可以核对布局、场景、基线和练习入口。

进入世界后执行命令打开六节教学：

```text
/ponderui ponder_legacy:production/early_oil_line
```

也可在 Ponder 分类中打开“前期石油生产线”。四台机器的原有教学后面会追加六节生产线教学。场景和分类 ID 沿用旧版，以便已有 FTB 引用继续使用。

六节依次为全线与物资、模块与锅炉供汽、勘探抽油、批次分馏、柴油发电、排查与自动化升级。使用既有暂停、步骤跳转、重播和人物皮肤控件。

本教学是 **前期半自动批次线**：液体及能源有真实管线布局，锅炉原料、分馏原油及副产物由玩家通过 GUI 转存。不会假装普通液管能自动分离多个输出罐。自动化升级仅说明末影液管及过滤方案，不把高阶材料列为前期必需品。

## 物资与结构

先按各机器原有蓝图搭建完整结构；本图用真实注册结构的最小方案，非整机静态外观模式。控制器朝北，共享基础功能仓在控制器右邻的局部 `(1,0,0)`。

| 站点 | 安装组件（各 1 件） | 实际接线 |
| --- | --- | --- |
| 低压蒸汽锅炉 | I 级物品、流体 | 北侧液体输出；水和燃料从 GUI 手动加入 |
| 简易井口抽油机 | I 级流体 | 北侧蒸汽输入；下方原油输出 |
| 常压分馏塔 | I 级物品、流体 | 北侧蒸汽间歇输入；原油与产物在 GUI 按批转存 |
| 燃油发电站 | I 级流体、能源 | 北侧柴油输入；下方能源输出 |

新仓默认无组件。手持组件右键仓体安装，或放入专用组件槽。在 GUI“仓面”中按真实世界方位选择面，分别设置物品、液体、能量的输入/输出/禁用。上方是必需外壳，不能为了接管拆壳。输入、输出不是两种不同的组件。

准备水、煤或木炭、空桶、独立水/原油/柴油/润滑油罐、煤箱、沥青箱、液体导管、能量导管和基础电容库。演示用一桶水、八份煤作测试备料，不是最低消耗或无限供给保证。现有 I 级流体组件输入和输出各有四罐，每罐 5000 mB。

## 一条线怎样运行

1. 水和燃料进入锅炉，预热至至少 100℃ 后产 `ic2steam`。蒸汽干线只输蒸汽，分别送泵和塔；前三站不需要启动 FE。
2. 先完成区域勘探，在当前区块有剩余油藏处搭泵。每 400 刻最多抽 250 mB 原油，扣 40 内部汽量；油藏有限，不能任意摆泵或重复勘探刷油。
3. 原油从仓下方独立管沟去缓冲罐。管端相对于机器/罐设置抽取和插入；抽取端设无需红石。不同流体的普通液管必须断网，不能相邻自动连通。本图原油沟比蒸汽干线低两层。
4. 塔北侧先禁用，把五桶原油倒入同一个输入罐，占住 5000 mB 的原料槽。再短时开北侧供汽，内部汽量达到至少 400 后关闭，且必须在原油罐耗尽前关闭。GUI 补油不受该面禁用影响；其他罐的残汽可保留继续转换。
5. 每 600 刻，一批 1000 mB 原油和 80 内部汽量产出 700 mB 柴油、200 mB 润滑油、沥青 1 个。五批累计 3500/1000 mB 和沥青 5 个；用普通桶可搬三桶柴油、一桶润滑油，剩余 500 mB 柴油留在仓中。
6. 需要先利用首批时，可分别用两个空的 `ic2:fluid_cell`（通用流体单元）从输出格取 700/200 mB，转存到不同罐。它允许部分液量，普通桶不允许。不混用两套方案的收支账。
7. 柴油罐用专用液管喂发电仓，能量从仓下方经能量管进基础电容库。基础型是 `enderio:block_cap_bank` metadata 1，metadata 0 是创造型，不可混用。

真实操作不能以演示刻数替代配方耗时。首次空管要灌管并积存流体，普通管的上升段还可能需要先充满；四轮是泵累计产出 1000 mB，不保证缓冲罐此刻已收到一桶。演示跳过了这些等待。

## 储存、产能与排查

柴油、润滑油必须分罐，沥青单独放箱。塔下方在基础方案中不接普通液管抽油，液体输出面保持禁用；没有“每面指定某个罐槽”的隐藏功能。

单批柴油可运行 700 刻（35 秒），发电 179200 FE。发电时为 256 FE/t；一台泵的原油供应长期理想平均只支持约 112 FE/t。储罐只能平滑供料，不能提高产量。理论持续满功率至少三台泵，并且蒸汽、油藏、运输及所有副产物出口都充足；本小型教学不承诺持续满载。

故障按顺序检查结构/组件、方位、温度与供料、管端模式和红石条件、输出空间、油藏与供料速度。不要只抽柴油却把润滑油和沥青堵住。高级自动化需要末影液管的多流体端点过滤，不能用锁定普通管替代。
