# 石油线操作推演（0.3.4-beta 候选）

## 本次改善

0.3.3 的六节教学能展示结构与流程，但资源变化由脚本给出，不能让玩家亲手试接线、进料或排错。新版本保留原演示，新增独立的五站操作推演。

这是本地教学账本，不是 MMCE 原 GUI，不会连接真实机器、真实管道、背包、任务结算或网络交互。它不替代整合包中的实际搭建和作业验收。

## 入口

安装同版本的 Ponder 本体和可选的前期石油生产线附属包。附属包的文件名及适用条件见 [安装指南](EARLY_OIL_LINE_033.md)。

进入世界后打开原有教学：

```text
/ponderui ponder_legacy:production/early_oil_line
```

在这六节油线教学的底部，点击书本图标（提示“石油线操作推演”）；单人模式下也可以使用既有 Ctrl+J 练习快捷入口。其他教学仍走原有练习路径，不把未适配的模组菜单伪装成油线操作台。

打开时暂停三维演示，返回时保留同一个演示界面、步骤与取景。练习状态与教学时间轴分离，不提供伪倒退；重置将重新准备本轮虚拟物料，关闭会释放状态。返回再进入是新的一轮，不恢复旧练习库存。

入口会再次核对本包原有的六个脚本/配置/结构基线文件。若文件改变或不可安全读取，留在演示并提示操作台不可用，不沿用旧配方默默演算。

## 五站操作

| 站点 | 可操作内容 | 观察内容 |
| --- | --- | --- |
| 锅炉 | 安装组件、加水、加煤、接通北侧蒸汽干线 | 温度、燃料、水和蒸汽余量 |
| 抽油 | 安装组件、确认示例勘探条件、开下方原油输出、注入/排除串液故障 | 有限油藏、抽油进度、仓内原油与累计产出 |
| 分馏 | 安装组件、从原油缓冲罐加油、短时开关北侧供汽 | 原油输入、内部汽量、残汽、产物和加工进度 |
| 储存 | 选择普通桶或通用流体单元、分别取柴油/润滑油/沥青 | 原油管滞留量、各罐存量、副产物箱与故障 |
| 发电 | 安装组件、开柴油供料、开下方能源输出、开示例负载 | 机内缓冲、电容库、累计发电和负载耗电 |

时间可以暂停、按 1 倍或 20 倍推进，也可单次推进 20 秒。手动操作会先暂停，便于阅读结果；切站、翻页和调整窗口不会清空本轮资源。长中文、反馈、统计和目标均分页，窄窗口使用分面板视图。

本轮示例资源有限：备水 8000 mB、煤 8 份、示例油藏 12000 mB。确认勘探条件只影响本轮推演，重复点击不能补油，也不代表在真实世界已经完成勘探。

## 练习目标

1. 准备锅炉组件、水和燃料，并预热至 100℃。
2. 满足勘探条件并累计抽出 1000 mB 原油。
3. 灌管后让原油缓冲罐实际收到 1000 mB。
4. 先保留原油输入槽，短充汽后关闭，再完成一批分馏。
5. 分别收集至少 700 mB 柴油、200 mB 润滑油和一个沥青。
6. 累计发电 179200 FE，且曾将电输出到电容库。

目标是当前练习的检查项，不是 FTB 任务，不发奖励、不写任务进度。已完成目标会锁存在本轮记录中，取走原料或继续耗电不会撤销此前完成的步骤。

分馏开汽本身不是实际配方失败条件；“先关汽”是本练习要求的安全操作目标，避免原油耗尽后被蒸汽抢槽。已有汽量不会因关闭供汽而消失。只投入一桶原油也能完成首批：批次开始时即扣除本批原油与蒸汽，随后关闭供汽仍被视为正确操作，不要求输入罐还剩一桶原油。按原教学准备五桶原油也可继续多批加工。

普通桶一次要求整 1000 mB；首批 700/200 mB 应用通用流体单元分别移出。选择普通桶积攒更多批也可完成，不把两套收支叠加计数。

## 模型边界与剩余不足

- 配方原料、产物和持续时间使用当前已核对数据；温度采用简化的净升温模型，没有复刻完整热损失。蒸汽分支优先级、每刻输送与普通管灌管模型也被简化，不能据此承诺真实网络速度。
- 显式保留泵仓、管内、储罐、分馏输出、发电机内部缓冲、电容库和负载账本，不凭空删除产物或把电容满误写成必然立刻停机。
- 目前是五站状态操作，不是六面仓体的完整可视化接线编辑器，也不是物品拖拽过关系统。
- 本轮操作尚不实时驱动原三维演示中的方块、人物与储罐外观；返回后仍是原教学时间轴，不把不同状态混成一张图。
- 界面不调用 MMCE 或 Ender IO 的真实加工/输送，不声称是真实机器界面适配。其余模组菜单仍需明确适配器。
- FTB 返回上下文只保留给活动演示直接拥有的练习子界面；无关窗口、错误父界面、返回任务书过程中的迟到子界面仍按原规则清理。
