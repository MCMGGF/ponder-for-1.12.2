## 原因与修改

1. `PreviewGlQueries` 反射查询原生 LWJGL，绕过 Actinium 对固定管线状态的字节码重定向。实际客户端启用 OpenGL Core Profile / FFP 模拟；原生颜色、矩阵快照不代表模拟状态，恢复这些数据会破坏后续绘制。新增统一运行时选择入口，优先读取已安装 Actinium 的 `GLStateManager`，仅在该类不存在时使用 LWJGL 2/3。接口或调用失败保持可见。颜色快照、矩阵保护、世界投影、静态模型及界面诊断快照共用该入口。
2. 石油线脚本与内容配置已更新，旧的两套完整基线均不匹配。重新核对四站结构、基础配方、流体和组件约束后添加第三套成对基线；旧基线及混合版本拒绝机制保留。当前抽油仍为 400 刻/40 内部汽量/250 mB 原油，分馏仍为 600 刻/80 内部汽量/1000 mB 原油→700 mB 柴油、200 mB 润滑油及 1 沥青，发电仍为 20 刻/20 mB 柴油/256 FE/t。
3. 当前 `content.json` 为 41,672,260 字节，超过旧的 32 MiB 上限。仅将内容配置上限提高到 64 MiB；普通文件仍限 8 MiB，仍采用流式精确哈希和路径检查。资料失败继续显示红色错误教学，并在同一索引代际对相同连续原因去重记录原始异常。
4. 版本更新为 0.3.6-beta。主产物编译目标修正为 Java 25 普通字节码；原有 stock Forge 服务端兼容 shim 的 Java 8 目标保留。公共 API、场景 ID、配置格式及实际机器配方未改变。
